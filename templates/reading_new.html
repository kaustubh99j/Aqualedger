How consumption is calculated

Consumption (L) = (Current − Previous) × 1,000

The previous value is locked to the latest reading so the meter chain stays continuous. A reading lower than the previous value is rejected.

Example: 145.320 m³ → 145.680 m³ = 360 litres.
